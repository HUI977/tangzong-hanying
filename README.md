# 唐踪汉影 · 长安西安双城舆图

把**唐代长安城一百一十坊**按真实地理坐标叠在**今日西安**地图上，拖动一根滑杆，穿越一千三百年。

> 朱雀大街的走向、东西两市的轮廓、大明宫的宫墙——它们都还压在今天的西安城下。

## 来源与二次开发

本项目是基于开源项目 **[xianmap](https://github.com/qiaoshouqing/xianmap)**（作者 [qiaoshouqing](https://github.com/qiaoshouqing)）的**二次开发成果**，谨此致谢。

上游项目确立了「唐长安按真实坐标叠加今日西安」的构想，并提供了完整的坊界复原数据、图层构建逻辑与「绢本设色」视觉体系——**本项目的核心数据与设计基础来源于此**。

本项目的改动主要是：

- **框架重写**：React 19 + TanStack Router → **Vue 3.5 + vue-router 4**
- **数据扩充**：新增关中帝陵、周秦汉遗址、汉城十二门、坊位索引（复原数据由 86 KB 扩充至 154 KB）
- **功能新增**：17 座名坊的图文卡（人物生平 / 诗作原文 / 大事年表）、POI 多图轮换、Canvas 手绘图标

完整的改动范围与授权说明见 **[NOTICE.md](NOTICE.md)**。

## 这是什么

一个「古今对照」的历史地理可视化应用。唐长安城的坊墙、宫城、两市、渠水、城门按考古复原坐标绘制为矢量图层，与今日西安的矢量底图精确套合；滑杆从「今」推到「古」，唐图渐显、今图退后。

点击任意位置，会告诉你**此地唐时在何处**；点到有典故的坊（如靖安坊、平康坊、崇仁坊），会展开一册古籍画册式的图文卡——坊中住过的人、写下的诗、发生的事。

## 功能

| 功能 | 说明 |
|---|---|
| **古今穿越滑杆** | 25+ 个唐图图层的不透明度联动，唐图全开时底图自动退后避免文字打架 |
| **点击定位** | 点地图任意处，解算该坐标在唐长安城中的位置（坊 / 宫城 / 两市 / 渠水 / 城外） |
| **名坊图文卡** | 17 座名坊的富结构化资料：坊中人物（含生卒与生平）、诗作与作品（含原文节选与创作背景）、大事年表 |
| **诗词与轶事** | 咏长安的古今诗词、唐代人物轶事，可点击飞到对应地点 |
| **今日寻迹** | 24 处今日可亲访的唐迹对应点（大雁塔、小雁塔、兴善寺、青龙寺……），一键飞到 |
| **关中帝陵** | 秦、汉、唐三代帝陵按朝代分色的方印点标，点击查看陵主与形制 |
| **周秦汉遗址** | 丰镐、阿房宫、汉长安城、建章宫等遗址范围图层 |
| **五语界面** | 简体中文 / 繁體中文 / English / 日本語 / 한국어 |

## 技术栈

- **Vue 3.5**（`<script setup>` + TypeScript strict）
- **MapLibre GL JS 5** —— 矢量瓦片渲染，图层叠加与透明度控制
- **Vite 6** —— 构建工具，`base: './'` 支持任意子目录部署
- **vue-router 4** —— history 模式，路由基准从部署路径自动推断

### 环境变量（可选）

项目**零配置即可运行**——不配置任何环境变量时会自动降级：

```bash
cp .env.example .env.local
```

| 变量 | 作用 | 未配置时的表现 |
|---|---|---|
| `VITE_MAPTILER_KEY` | MapTiler 矢量底图 | 回退 MapLibre 演示底图（无中文注记） |
| `VITE_GA_ID` | Google Analytics | 不加载统计脚本 |
| `VITE_WARD_GEN_ENDPOINT` | 坊卡补图端点 | 缺失的坊图显示占位图 |

> 部署到生产时，请为自己的 MapTiler key 配置 **Allowed Origins** 域名白名单，避免额度被盗刷。

## 数据与考据

唐长安城的复原数据是本项目的核心（`src/data/changan.ts`）。

**配准锚点**（以 OSM/WGS84 实测遗址坐标为基准）：

| 锚点 | 坐标 |
|---|---|
| 明德门遗址公园（郭城正南门，朱雀大街南端） | ≈ 108.9373, 34.2065 |
| 含光门遗址博物馆（唐皇城南墙含光门原址） | ≈ 108.9291, 34.2526 |
| 丹凤门（大明宫正门，郭城北墙线） | ≈ 108.9595, 34.2828 |

由此推出皇城南墙纬度 34.25267（与含光门实测差 < 20m），并据此按《唐六典》「皇城之南，东西十坊，南北九坊；皇城之东西各十二坊，两市居四坊之地，凡一百一十坊」的记载，程序化生成全部坊多边形。

**校验结果**：大雁塔落晋昌坊、小雁塔落安仁坊西缘、大兴善寺落靖善坊正中、青龙寺落新昌坊、大唐西市落西市原址——均吻合。

**坊名与排布**依据《长安志》（宋·宋敏求）卷七至卷十。坊中人物、诗作、大事年表取自两《唐书》《唐六典》等公开史料，逐坊核实。

> 本项目的定位是**示意图**而非考古测绘成果，坊界与遗址范围均为按文献与实测锚点推算的近似值。

## 项目结构

```
src/
├─ data/
│  ├─ changan.ts        # 唐长安复原数据：110 坊矩阵、坊典故、唐迹、帝陵、遗址

├─ components/
│  ├─ MapView.vue       # 地图核心：图层构建、透明度联动、交互与弹窗

├─ pages/               # 地图页与考据页
├─ i18n/                # 五语文案
└─ index.css            # 全局样式（朱砂 / 绢色 古籍风）
```
